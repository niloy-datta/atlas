# ATLAS Frontend

Next.js App Router, React, strict TypeScript, Tailwind infrastructure, Vitest, Testing Library, and Playwright.

Phase 1 supplies a semantic structural shell only. Final visual design, route composition, imagery, and component tokens wait for the approved design handoff.

## Commands

- `npm run dev`
- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build`
- `npm run test:e2e`

Set `NEXT_PUBLIC_ATLAS_API_URL` to change the backend origin. The local default is `http://localhost:8080`.
